Pulse Grid – Electrical Signal Visualization

An interactive, web-based visual experiment that transforms a simple dot grid into a dynamic electrical pulse visualization. Click anywhere on the grid to create glowing waves that spread across the screen.

Built using HTML, CSS, and JavaScript, this project combines interactive visuals, smooth animations, and customizable themes to create an engaging digital experience.

Features

 Click anywhere on the grid to generate visual pulses.
 Watch glowing waves spread across the grid.
 Switch between Dark, Midnight, Light, Circuit Board, and Graph Paper themes.
 Reset the grid and clear the visual effects.
 responsive pulse animations.
 
Technologies Used

 HTML5 – Website structure and layout.
 CSS3 – Styling, themes, glowing effects, and animations.
 JavaScript – Interactive grid, pulse generation, and theme switching.
